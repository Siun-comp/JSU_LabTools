확인한 내용
초기 화면의 이름·버전과 페이지 접속을 확인했습니다.

이 기록은 계산 정확성·임상 성능·LoD 검증 완료를 의미하지 않습니다.

입력과 주요 기능

Excel 또는 Quick Paste로 형광 데이터를 입력하고, 곡선과 선택세트를 관리합니다. Scale·Box zoom, Style·Label·Legend, Threshold 검토, 내보내기와 Analysis XLSX 저장·복원을 제공합니다.

포털에서 파일·선택·설정·결과를 전달하지 않습니다. 입력은 열린 Plot 탭에서 진행합니다.

결과를 사용할 때

  • 원본 형광값을 자동 smoothing·normalization·baseline correction하지 않습니다.
  • Threshold의 Positive/ND는 사용자가 지정한 기준의 교차 상태입니다. 임상 판정이나 LoD 분석의 검출 성공·실패로 자동 해석하지 않습니다.
  • 원본 Excel은 별도로 보존하세요. Analysis XLSX는 분석 상태의 저장·복원에 쓰며, Selected Data XLSX는 선택 데이터 출력용입니다.

데이터 처리 안내

기존 문서와 초기 화면은 브라우저 내부 분석을 안내합니다. 포털에는 분석 데이터를 입력하지 않으며 외부 도구 실행 시 데이터나 URL 매개변수를 추가하지 않습니다.

이번 포털 확인에서는 Plot의 파일 입력·계산·내보내기·복원이나 전체 통신을 다시 시험하지 않았습니다.
