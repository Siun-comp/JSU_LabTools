정리와 변환

/…/로 감싼 모든 구간, 공백·탭·줄바꿈, -를 제거합니다. 원문은 입력창에 유지하고 가운데 창에 삭제 부분을 붉은 굵은 글씨로 표시합니다. T/U 혼재는 혼재 오류·표기 정리 안내를 남기고 출력을 허용합니다. DNA 출력은 U, RNA 출력은 T를 가운데에서 표기 변경으로 강조하고 각각 T/U로 바꿉니다. 숫자·기타 미지원 문자와 닫히지 않은 slash는 출력 차단 오류입니다.

기본 출력은 입력의 대소문자를 유지합니다. ‘전체 대문자’ 버튼은 출력에 대문자를 적용하며 Clear로 초기화합니다. Reverse는 순서 반전, Complement는 선택한 출력 종류의 상보입니다. 두 체크를 켜면 Reverse Complement가 됩니다. 출력 DNA를 선택하면 U→T, RNA를 선택하면 T→U로 양방향 표기를 변환합니다. 입력 종류를 추정하지 않으며 원문은 그대로 둡니다. 선택한 출력 표기로 바꾼 뒤 상보 변환하므로 A는 DNA 출력에서 T, RNA 출력에서 U가 됩니다.

Reverse 또는 Complement 하나만 켜면3′→5′, 둘 다 또는 둘 다 해제면5′→3′입니다. 모든 결과는 입력 원문에서 다시 계산합니다. 복사는 보여준 출력만 사용합니다.

최종 길이·지원 코드·FASTA

최종 출력의 염기 수를 nt로 표시하고 DNA 출력은 이중가닥 길이에 대응하는 bp도 표시합니다. 실제 이중가닥 형성 여부는 판단하지 않습니다. 수정 표기·삭제 문자·FASTA 이름/줄바꿈은 길이에서 제외하고 N 등 정상 IUPAC 문자는 1염기로 셉니다. 여러 기록은 기록별 길이와 합계를 구별하며 서열을 합치지 않습니다.

DNA A/C/G/T 또는 RNA A/C/G/U와 R/Y/S/W/K/M/B/D/H/V/N을 지원합니다. R↔Y, K↔M, B↔V, D↔H, S/W/N은 그대로입니다. 수정 표기 구간의 의미나 기본 염기를 추정하지 않습니다.

FASTA 입력은 단일 기록도 이름과 기록 순서를 보존하여 자동으로 FASTA로 출력합니다. 이름이 중복되면 경고합니다. 일반 서열을 FASTA로 바꿀 때만 이름을 지정하며 줄 길이는 모든 FASTA 출력에 적용합니다. FASTA에도 현재 결과 방향을 그대로 적용하므로3′→5′ 결과는 화면의 방향 안내를 확인하세요. 이름에 처리 이력을 자동 덧붙이지 않습니다.

한계와 확인

원본 최대1,000,000자·기록1,000개. 강조 미리보기는12,000자까지 표시하고 계산·출력·복사는 전량입니다. 출력 차단 오류가 있으면 전체 출력을 차단합니다. T/U 혼재만으로는 차단하지 않습니다. 가운데의 공백 표시 기호는 출력에 포함되지 않습니다.

계산·화면 검증과 사용자 실사용은 구별합니다. 실제 사용자 서열 대조는 확인 전입니다. 전체 대문자 버튼은 출력 옵션이며 다시 누르면 원래 대소문자로 돌아옵니다. FASTA의 -를 제거하면 정렬 gap 정보와 정렬 위치는 보존되지 않으며 화면에 안내합니다. GC%·Tm·분자량·생물학적/임상 판정·제조사별 수정 염기 복원은 제공하지 않습니다.

Sequence 입력은 다른 도구로 자동 전달하지 않습니다.
