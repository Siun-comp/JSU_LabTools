사용 순서

  1. 최종 반응 전체 부피, 반응당 Mix 투입량, 준비할 반응 수를 입력합니다.
  2. F1/R1/P1에 목표/Stock 농도를 입력합니다. F/R/P/Q/Plasmid 성분을 최대15개까지 추가하거나 계산에서 제외할 수 있습니다.
  3. Plasmid는 질량·copies·몰농도 단위를 각각 선택합니다. 질량↔copies에는 전체 분자량 또는 명시적으로 선택한 전체 dsDNA 길이 근사가 필요합니다.
  4. 이론 부피 계산을 누르고 반응당 부피·전체 준비량·Mix 내부 농도를 확인합니다. 단위 변경을 포함해 입력을 바꾸면 다시 계산해야 합니다.
  5. 필요하면 전체 준비량을 수동 조정하고 사용하는 피펫의 간격·최소·최대량을 입력해 예상 목표 편차와 준비량 부족을 검토합니다.
  6. Excel 양식으로 복사한 뒤 새 빈 영역에 원본 서식을 유지하여 붙여넣습니다. HTML에는 맑은 고딕9pt를 지정하지만 값만 붙이면 대상 서식이 적용됩니다.

방법과 결과 의미

농도 목표의 필요량은 목표 농도×최종 반응 부피, 반응당 질량/copies 목표의 필요량은 입력 목표량입니다. Stock 부피는 필요량÷Stock 농도, TE는 Mix 투입량−Stock 부피 합계, 전체 준비량은 반응당 부피×반응 수입니다.

copies는 Plasmid 분자 수의 평균 기대량입니다. 질량 환산에는 전체 분자량(g/mol)이 필요하며 전체 dsDNA 길이×650 g/mol/bp는 선택한 근사 방법입니다. insert/amplicon 길이로 대체하지 않습니다. Avogadro 상수는 6.02214076×10²³ mol⁻¹입니다. 환산 근거를 결과·복사에 남깁니다.

화면의 0이 아닌 결과는 절댓값0.001 이하에서 대문자 E 지수로 표시합니다. 유효숫자는 최대12자리이며 표시 반올림을 계산에 적용하지 않습니다. 단위와 복사 숫자값을 유지합니다.

한계와 데이터 처리

균일 혼합과 부피 가산을 가정합니다. 손실·장비 오차·검출 성공·임상 판정·유전자 수를 자동 추정하지 않습니다. 매우 작은 이론량이 실제 분주 가능한 양이라는 뜻은 아닙니다. 자동 반올림·TE 보충·여유량 추가·질량↔몰농도 직접 환산은 제공하지 않습니다.

입력은 해당 브라우저 탭에서만 처리합니다. 서버 저장·외부 계산·자동 데이터 전달은 없습니다. 새로고침하면 입력이 사라집니다. 클립보드는 이론 결과와 조건·단위·버전만 복사하며 제외행과 실제 조정량은 포함하지 않습니다. 파일 export와 입력 복원 기능은 없습니다.
