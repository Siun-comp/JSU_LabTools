사용 순서

  1. 최종 반응 전체 부피, 반응당 Mix 투입량, 준비할 반응 수를 입력합니다.
  2. F1/R1/P1에 목표/Stock 농도를 입력합니다. F/R/P/Q의 Stock 기본값은 수정 가능한100µM입니다. 성분 수15개 제한 없이 추가하거나 포함 체크로 계산에서 제외하며 번호·입력 개수를 확인할 수 있습니다.
  3. Excel 목록은 이름 / 최종 반응 농도µM / StockµM의3열을 붙여넣고 미리보기 후 추가 또는 전체 교체합니다. 빈 Stock만100µM로 채우며 명시한0은 오류입니다. 첫 제목행은 체크로 제외합니다. Plasmid는 단위 정보가 필요하므로 개별 입력합니다.
  4. Plasmid는 질량·copies·몰농도 단위를 각각 선택합니다. 질량↔copies에는 전체 분자량 또는 명시적으로 선택한 전체 dsDNA 길이 근사가 필요합니다.
  5. 이론 부피 계산을 누르고 반응당 부피·전체 준비량·Mix 내부 농도를 확인합니다. 단위 변경을 포함해 입력을 바꾸면 다시 계산해야 합니다.
  6. 분주 부피 조정에서 구간별 세부/일반 간격 또는 직접 입력을 선택하고 부피 제안을 누릅니다. 세부 간격은≤2µL:0.002 / >2~20µL:0.02 / >20~200µL:0.2 / >200~1000µL:2입니다. 정확히2·20·200은 더 작은 구간을 사용합니다. 정확한 이론량에서 가장 가까운 배수로 제안하고 정확히 중간이면 위쪽 배수입니다. 제안값은 직접 수정할 수 있으며, 수정 후 구간·간격 검사는 실제 최종 선택량으로 다시 수행합니다. TE는 목표 전체량의 잔여 부피를 해당 간격에 맞춰 반올림합니다. 실제 합계 차이와 예상 최종 농도 편차를 확인하며 TE 분할 분주는 요구하지 않습니다.1000µL 초과량은 간격 직접 입력을 사용합니다. 직접 입력 모드의 최소·최대량은 선택 입력입니다.
  7. 최종 농도 빠른계산은 예전 생산 문서의 사용 부피를 확인하는 독립 팝업입니다. 넣는 용액 농도·1반응 투입 부피·최종 반응 전체 부피를 입력합니다. Stock이면 Stock농도/부피, Mix이면 Mix자체농도/부피를 사용합니다. 결과는 입력 농도 단위를 유지하며 메인 배합을 변경하지 않습니다.
  8. 이론값을 Excel 양식으로 복사한 뒤 새 빈 영역에 원본 서식을 유지하여 붙여넣습니다. 테두리와 예약 빈행 없이 계산 포함 성분만 복사하고 합계행이 바로 이어집니다.3성분은7행·10열입니다. HTML에는 맑은 고딕9pt를 지정하지만 값만 붙이면 대상 서식이 적용됩니다.

방법과 결과 의미

농도 목표의 필요량은 목표 농도×최종 반응 부피, 반응당 질량/copies 목표의 필요량은 입력 목표량입니다. Stock 부피는 필요량÷Stock 농도, TE는 Mix 투입량−Stock 부피 합계, 전체 준비량은 반응당 부피×반응 수입니다.

copies는 Plasmid 분자 수의 평균 기대량입니다. 질량 환산에는 전체 분자량(g/mol)이 필요하며 전체 dsDNA 길이×650 g/mol/bp는 선택한 근사 방법입니다. insert/amplicon 길이로 대체하지 않습니다. Avogadro 상수는 6.02214076×10²³ mol⁻¹입니다. 환산 근거를 결과·복사에 남깁니다.

화면의 0이 아닌 결과는 절댓값0.001 이하에서 대문자 E 지수로 표시합니다. 유효숫자는 최대12자리이며 표시 반올림을 계산에 적용하지 않습니다. 단위와 복사 숫자값을 유지합니다.

한계와 데이터 처리

균일 혼합과 부피 가산을 가정합니다. 손실·장비 오차·검출 성공·임상 판정·유전자 수를 자동 추정하지 않습니다. 매우 작은 이론량이 실제 분주 가능한 양이라는 뜻은 아닙니다. 사용자가 버튼을 누를 때만 분주 간격에 따른 부피를 제안하며 이론값은 보존합니다. TE도 간격에 맞춰 반올림하고 합계 차이를 표시합니다. Stock합계가 계획 전체량을 넘으면 차단하며 다른 성분을 몰래 바꾸지 않습니다. 여유량 추가·질량↔몰농도 직접 환산은 제공하지 않습니다.

입력은 해당 브라우저 탭에서만 처리합니다. 서버 저장·외부 계산·자동 데이터 전달은 없습니다. 새로고침하면 입력이 사라집니다. 클립보드는 이론 결과와 조건·단위·버전만 복사하며 제외행과 실제 조정량은 포함하지 않습니다. 파일 export와 입력 복원 기능은 없습니다.
