Amplification Analysis

CFX 내보내기와 Excel 증폭 곡선의 Threshold · 반복 · STD 정량 · 개별 4PL/5PL 분석

열기 파일 입력은 열린 분석기 탭에서 진행합니다.

버전과 상태

확인 내용
합성 자료 자동 시험(단위·브라우저) · 실제 CFX 내보내기 파일 읽기 구조 확인

CFX 내보내기 입력은 이번 베타에서 처음 공개합니다. 실제 파일 화면과 사용성은 실제 사용 중 확인하고 보완합니다. 기존 Plot T는 현재 링크로 계속 사용할 수 있습니다.

입력

CFX 내보내기: CFX Maestro의 Quantification Data에서 내보낸 Excel을 그대로 엽니다. 형광별 시트의 Cycle 열과 well 열을 읽고 값은 고치지 않습니다. Cycle은 1부터 빠짐없이 이어질 때만 받습니다. 여러 파일을 한 번에 열 수 있고, 같은 well이라도 파일마다 다른 곡선입니다.

파일마다 well 배치표에 시약·검체·구분(Unknown / STD / PC / NTC / NC)·농도를 적습니다. Excel에서 복사한 범위를 붙여넣을 수 있고, 빈 칸은 바로 위 행을 이어받습니다. 시약에 -를 쓰면 그 well은 등록하지 않습니다. 정렬은 가로 순·세로 순만 있습니다. 등록한 뒤에도 well 배치 수정으로 고칠 수 있습니다.

형광은 CFX Channel 1~5로 묶어 표시합니다. 한 시약이 Channel마다 다른 타겟을 보는 multiplex라면 시약별 Channel 타겟을 적을 수 있습니다.

일반 Excel·붙여넣기: 첫 시트의 각 열이 한 곡선입니다. 1행 검체 · 2행 시약 · 3행 Channel 코드(1~5) · 4행 이후 수치입니다. X는 수치 행 순서 1, 2, 3…입니다.

반복·STD·개별 곡선 분석

같은 파일 안에서 시약·검체·구분(STD는 농도까지)이 같은 well을 반복으로 묶어 Channel과 적용 Threshold별 평균, 표준편차(n−1), 유효 수를 보여 줍니다. 다른 파일의 well은 묶지 않습니다. 이상값 제거나 PC·NTC·NC에 따른 판정은 하지 않습니다.

STD는 농도별 평균 교차값으로 회귀합니다. 배치표에서 구분을 STD로 적은 well은 농도와 함께 미리 채워지고, 체크한 곡선을 농도 행에 추가하는 방식도 그대로입니다. 범위 밖 Unknown은 외삽으로 구별하며, 시약 이름 차이는 자동 제외 조건이 아닙니다.

4/5PL 분석은 실행 당시 체크한 곡선만 분석합니다. 변곡점은 Ct/Cq가 아니며, 모델 비교는 참고 판단입니다. 적합 곡선은 그래프에 점선으로 겹쳐 볼 수 있습니다(미리보기 전용).

저장과 재열기

분석 저장은 원 수치·배치표·선택·제외·순서·스타일·축·Threshold·STD와 4/5PL 결과를 자체 작업 XLSX에 보존합니다. CFX 곡선이나 4/5PL 결과가 있는 분석은 schema 16으로 저장되어 v0.1.0-beta.1에서는 열리지 않습니다. 그 밖의 분석은 schema 15로 저장됩니다. 기존 T 작업 XLSX 직접 이어하기는 지원하지 않습니다.

지원 범위

CFX에서 baseline 처리까지 마친 값을 입력합니다. .pcrd 직접 열기·앱 baseline/melt 분석·실험 조건 관리는 현재 범위 밖입니다. 원본 파일과 실험 조건은 기존 방식으로 따로 보관합니다.

분석 데이터는 브라우저에서 처리합니다. 포털은 분석 파일이나 결과를 전달하지 않습니다. 사용자 직접 저장·복사로 결과를 보관합니다.
