사용성은 실제 사용 중 확인하고 보완합니다. 기존 Plot T1.3.0은 현재 링크로 계속 사용할 수 있습니다.

입력과 선택

첫 시트의 각 열이 한 곡선입니다. 1행 검체 · 2행 시약 · 3행 형광 코드 · 4행 이후 Y 수치로 준비합니다. 형광은 1 FAM / 2 HEX / 3 TexasRED / 4 Cy5 / 5 Cy5.5입니다. 공란은 기존 방식으로 왼쪽 값을 이어받습니다.

X는 수치 행 순서 1, 2, 3…입니다. Ct/RFU 제목은 숨기거나 바꿀 수 있지만 수치·시간·단위가 자동 변환되지는 않습니다.

데이터 열기는 Excel과 자체 작업 XLSX를 함께 사용하며 추가·대체·새 분석으로 열기를 제공합니다. Run 체크는 STD 분석 포함과 Plot 일괄 선택, 개별 체크는 Plot 표시와 다음 4/5PL 대상을 정합니다.

STD와 개별 곡선 분석

Threshold를 적용한 뒤 농도 행에 체크 곡선을 추가합니다. 지정 STD 이외의 Run 포함·비제외 데이터는 자동 Unknown입니다. 형광/적용 Threshold별 세트에서 농도별 평균 교차값으로 회귀하며, 시약 이름 차이는 자동 제외 조건이 아닙니다.

STD 결과는 회귀선·개별 관측점·Unknown 농도와 수식입니다. 범위 밖은 외삽으로 구별하고 ND·미연결·잘못된 STD는 보류합니다. 결과 복사·그래프 복사·그림과 STD/Unknown을 포함한 결과 Excel을 제공합니다.

상단 4/5PL 분석은 실행 당시 체크한 개별 곡선만 분석합니다. Max slope · Inflection · 추정 Plateau · Rise width · Amplitude · Asymmetry와 수치 검토 사유를 제공하고 raw 계수는 Advanced Details에 있습니다. 모델 비교는 참고 판단이며 Primer/Probe 성능이나 임상 결과를 자동 판정하지 않습니다.

저장과 재열기

분석 저장은 원 수치·선택·제외·Run 포함·스타일·축·Threshold·STD 설정과 결과를 자체 작업 XLSX에 보존합니다. 기존 T 작업 XLSX 직접 이어하기는 지원하지 않으며 기존 T에서 재현합니다.

4/5PL 결과는 탭의 임시 결과입니다. 필요하면 Excel에 복사하세요. 입력 교체·탭 닫기·새로고침으로 초기화되며 작업 재열기 후 다시 분석합니다.

지원 범위

외부에서 처리한 Excel/paste 입력을 사용합니다. CFX native 직접 입력·앱 baseline/melt 분석·일반 반복 평균/SD/CV·실험 조건 관리는 현재 범위 밖입니다. 원본 파일과 실험 조건은 기존 외부 관리 방식에 보존합니다.

분석 데이터는 브라우저에서 처리합니다. 포털은 분석 파일이나 결과를 전달하지 않습니다. 사용자 직접 저장·복사로 결과를 보관합니다.
