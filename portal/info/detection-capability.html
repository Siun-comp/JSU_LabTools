사용 순서

  1. 분석을 선택하고 단위·목표 확률 또는 시험계획의 기준을 입력합니다.
  2. 직접 입력, Excel의 값 붙여넣기, 이 도구의 v3 양식 중 하나로 입력합니다.
    붙여넣기·양식 적용은 미리보기 확인 후 진행합니다.
  3. 계산 후 후보값·신뢰구간·보류 사유·방법과 출처를 함께 확인합니다.
    여러 LOT는 집단별로 계산하며 자동 취합하지 않습니다.
  4. 표·그래프 복사 또는 3시트 XLSX 결과서를 사용합니다.
    XLSX는 계산 결과 기록이며 셀을 바꿔도 재계산되지 않습니다.
  5. 작업을 이어갈 때는 JSON을 저장합니다.
    복원 후에는 다시 계산해야 하며 입력을 변경하면 이전 결과 출력이 차단됩니다.

계산 환경과 데이터

LoD·confirmation·LoQ는 브라우저 안의 webR에서 R을 실행합니다.
webR v0.6.0 / R·stats v4.6.0 / LoD MASS v7.3-65를 확인합니다.
LoD 적합은 epsilon=1E-12, maxit=200, CI dispersion=1을 사용합니다.
처음 R 분석을 실행할 때 고정 계산 환경을 외부에서 내려받습니다.
분석 입력을 외부 계산 API로 보내지 않습니다.
같은 세션의 준비 후 계산과 영구 오프라인 설치는 구별됩니다.

확인된 근거

현재 포털 작업본에서 고정 LoD/CI·검출률 CI 298 assertion, 입력·복원·출력 92 UI 그룹 및 2,309 assertion, 표준 예제 7집단·178 assertion을 확인했습니다.
서로 다른 검사 묶음이며 통계 사례 수로 합산하지 않습니다.
표준 LoD는 인쇄 소수 3자리 점추정 대조입니다.
일반 자료의 별도 적합 구현 전체 대조나 실제 품목 허가 적합성 확인을 완료했다는 뜻으로 확대하지 않습니다.

회사 보고서·원자료를 개발자에게 제공할 필요가 없습니다.
해당 시험계획·총오차·재검 처리·최종 보고 기준은 회사 내부에서 확인합니다.
이 도구는 한 집단의 계산 후보를 제공하며 최종 전체시험 결과나 임상 판정을 자동 확정하지 않습니다.
