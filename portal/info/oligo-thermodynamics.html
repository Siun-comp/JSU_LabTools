Oligo Thermodynamics

전체 DNA 서열에서 독립 oligo 구간을 선택하고 결합·접힘 모델값을 비교합니다.

열기 ↗초기 베타 · 모델 한계 확인

입력과 계산

단일 DNA/FASTA의 전체 서열에서 두 경계·숫자·±1·길이 고정으로 선택합니다. 선택 영역을 독립 A로, 완전 상보 B를 기본으로 계산합니다. 원본 좌표는 출처이며 선택 밖 전체 분자 folding을 계산하지 않습니다. 일반 A/C/G/T 선택2–60nt·부모10,000nt·입력 온도0–100°C를 지원합니다. 이 범위는 실측 정확도 검증 범위가 아닙니다.

반응 온도·최종 이온·A/B 농도를 입력합니다. 사용자 지정 시작 조건은60°C·Na50mM·Mg total3mM·dNTP total0.8mM·A/B각200nM·K/NH₄0입니다. 일반 반응 권장 조성을 뜻하지 않습니다.

모델과 수치 구분

Duplex는 DNA_NN4 고정 완전 상보 모델입니다. Mg 포함 조건에서는 Owczarzy2008 보정 Tm과 온도차를 제공합니다. Mg 조건의 ΔG/ΔH/ΔS는 제공하지 않습니다. 별도 ‘참고 · Mg=0’의 ΔG/ΔH/ΔS/Tm은 Mg만0으로 바꾼 값이며 실제 Mg 효과를 제외합니다. dNTP 독립 효과는 반영하지 않으며 단가염0이면 참고값을 제공하지 않습니다.

A/B hairpin은 각각 원래 입력 조건으로 고정 Primer3 THAL을 실행합니다. 단일 선택 구조이며 ensemble 접근성·실제 접힘 비율을 뜻하지 않습니다. 실측 UV hairpin12건의 제한된 대조에서 Tm MAE14.73°C 등 차이가 남아 있습니다. 구현 재현성과 실험 정확도를 구분하며 IDT 일치·속도·효율·형광·최적 설계를 보장하지 않습니다.

실시간 결과·보관·출력

수치 입력 후160ms 대기해 최신 요청을 Worker에서 자동 계산합니다. 자동 끄기·직접 계산·취소를 제공하며 입력 변경 즉시 이전 결과와 복사를 만료합니다. 접기/집중 보기와 수치별 설명을 제공합니다. 최대3개 보관·기준 비교·클립보드/TXT/CSV 출력은 계산 당시의 조건·좌표·모델을 보존합니다. Mg=0 참고 에너지를 실제 Mg ΔΔG로 사용하지 않습니다.

입력은 브라우저 메모리에서만 처리하며 자동 저장·외부 전송이 없습니다. 엔진은 같은 사이트의 정적GET으로 읽습니다. 전체 원문은 명시적 출력 옵션을 켠 경우만 포함합니다. 새로고침/종료/초기화 시 보관도 지워집니다.

적용과 한계·소스

일반 primer/probe·LAMP·OSD 등의 독립 영역 비교를 위한 도구입니다. Mismatch·RNA·수정/표지·효소·시간축·실제 반응 속도는 계산하지 않습니다. 다른 기존 Oligo-dimer 도구와 독립적으로 동작하며 입력을 자동 전달하지 않습니다.
