계산 의미

dsDNA·ssDNA·ssRNA·전체 Plasmid의 질량농도, 몰농도, 물리적 Copy 농도를 양방향으로 환산합니다.
MW가 없으면 가능한 결과만 표시하고, 선택한 MW 방법이 잘못되면 계산을 차단합니다.
평균법으로 자동 전환하지 않습니다.
Copy는 전체 분자 수이며 이중가닥 한 분자=1copy, 소수는 평균 기대량입니다.
표적 부위 수·LoD·검출 성공·임상 판정은 계산하지 않습니다.

길이 기준·직접 MW

길이는 전체 분자 기준입니다.
dsDNA/Plasmid의 웹 기준: NEBioCalculator 길이 모드(MW=615.94n+36.04, 확인v1.17.5), Thermo DNA Copy Calculator 기본값(MW=650n).
두 기준은 NA=6.022E23을 사용합니다.
Thermo 질량농도 입력은 copies/ng를 먼저 정수 반올림하고 Stock 농도와 곱하며, 몰농도는 Copy/NA로 계산합니다.
Thermo 몰/Copy 입력은 해당 MW·NA의 역환산이며 웹툴이 제공하지 않는 입력 경로입니다.
웹 기준은 길이 모드만 지원하며 외부 계산 API를 호출하지 않습니다.
기존650n 일반 근사·660n(Promega), ssDNA330n·ssRNA340n(Promega)와 서열/직접MW는 NA=6.02214076E23 및 기존 수치를 유지합니다.
Thermo Fisher/Ambion 기술자료의 별도 고정 근사식은 ssDNA: 길이×303.7+79.0, ssRNA: 길이×320.5+159.0, dsDNA/Plasmid: 전체 bp×607.4+157.9 g/mol입니다.
ssDNA 식은 5′ 인산1개, ssRNA 식은 5′ 삼인산을 포함하며 dsDNA 식에는 말단 상수가 있습니다.
이 Ambion 식은 지정 Thermo Copy Calculator의 기본650 및 NEBioCalculator 길이 식과 구별합니다.
제조사 이름이 같아도 사용하는 도구/자료와 NA·반올림 기준에 따라 결과가 달라질 수 있습니다.
완전 폐환 Plasmid 전용식이 아니며 선택한 시료의 구조에 맞춰 말단을 자동 변경하지 않습니다.
다른 조건의 정밀 계산에는 지원 조건의 일반 서열법이나 해당 전체 MW를 사용하세요.
원형/말단·개별 조성의 정밀 보정은 하지 않습니다.
직접 MW는 해당 분자 성적서 등의 값과 선택적 출처 메모를 그대로 사용합니다.
modification·counterion 등을 자동 추정하지 않습니다.

일반 서열의 이론 MW

이름이 있는 한 FASTA 기록 또는 일반 서열만 받습니다.
서열별 모델은 무수 유리산·평균 질량 기준입니다.
Biopython1.88의 평균 monophosphate 표와 H₂O18.0153 g/mol을 참고하여 자체 구현했습니다.
DNA A331.2218/C307.1971/G347.2212/T322.2085, RNA A347.2212/C323.1965/G363.2206/U324.1813 g/mol.
각 phosphodiester 결합에서 H₂O를 차감합니다.
선형 5′OH/3′OH는 5′인산 모델에서 HPO₃79.9799 g/mol을 한 가닥당 차감합니다.
HPO₃는 같은 참조의 H/P/O 평균 원자질량으로 유도하여 소수4자리로 정의했습니다.

선형5′인산/3′OH는 가닥당 n−1결합, 완전 폐환 원형은 n결합입니다.
dsDNA/Plasmid는 입력 가닥과 완전 상보 가닥을 모두 합산합니다.
선형 이중가닥은 두 가닥이 동일한 말단 상태라고 사용자가 선택합니다.
결과는 같은 조건에서의 이론 모델이며 실제 수정 상태·농도 측정·분자 구조의 정확성 보증이 아닙니다.
650/660 근사와 화학 기준이 달라 결과 차이를 단순 오류로 해석하지 마세요.
결과 옆에도 방법 차이를 안내합니다.
같은 시료의 조제·기록에는 동일한 MW 기준을 사용하세요.

입력 원문은 보존하고 ASCII 공백·줄바꿈과 대소문자만 계산에 맞춰 읽습니다.
U/T 변환이나 수정 표기 삭제는 없습니다.
모호염기·수정·다중 FASTA·DNA/RNA 불일치·nicked Plasmid·overhang·불완전 이중가닥·염/수화물·단일동위원소 질량·선형 외 RNA는 미지원입니다.
해당 조건의 알려진 전체 MW를 직접 입력할 수 있습니다.

기본 Vector·표시 보완

Plasmid·일반 서열에서 바이오닉스 공식 공개 파일의7항목을 명시적 버튼으로 불러옵니다.
pUC57-Amp의 두 제한효소 표기 항목은 제공 파일의 서열이 동일합니다.
pcDNA3.1(+) 공개 서열에는 모호염기 S 한 곳이 있어 불러오기에서 제외했습니다.
실제 납품 분자·insert·구조의 일치까지 검증한 자료는 아닙니다.
입력을 편집하면 편집 상태를 표시하고 원본 Vector 출처·자료 버전·서열 hash를 복사에 남깁니다.
불러오기 전 입력으로 되돌릴 수 있으며 구조·말단은 자동 변경하지 않습니다.

Copy 결과는 선택 단위에서1000 이상이면 소수 두 자리·3유효숫자의 지수 요약을 병기하고 복사합니다.
형식은0.00E+00, 1.00E+03=1000, 1.00E+06=1000000입니다.
원래 값·선택 단위·최대12유효숫자 주값과 계산 정밀도는 유지합니다.

Thermo Fisher Chemistry Guide의 DNA 올리고 MW는 sodium salt(pH 7) 기준입니다.
현재 앱의 무수 유리산 기준과 달라 일반적인 정확도 순위로 비교할 수 없습니다.
Chemistry Guide의 해당 염형 서열 모델은 현재 계산 방법으로 추가하지 않았습니다.
이번에 추가한 Thermo 평균 근사는 별도 Ambion 기술 지원 자료의 고정식이며 현재 일반 서열 모델을 교체하지 않습니다.
일반 서열·구조·말단이 정확하고 현재 화학 조건에 해당하면 평균법보다 구체적인 이론값입니다.
성적서의 전체 MW가 해당 수정·염형을 반영했다면 직접 MW가 더 적합할 수 있습니다.

내 시료의 선형 말단 선택

선형은 분자의 끝이 열린 형태일 뿐, 5′ 말단 인산의 유무까지 지정하지 않습니다.
일반 DNA/RNA 화학 합성 올리고는 별도 수정 없이 주문하면 보통 5′ OH/3′ OH입니다.
PCR 산물은 사용한 프라이머의 5′ 말단 상태를 이어받습니다.
두 프라이머가 비인산화이면 OH, 둘 다 5′ 인산화이면 인산1개 조건에 해당합니다.

5′ 인산화 주문이나 T4 PNK+ATP 등으로 인산화가 완료된 시료, 일반적인 제한효소 절단 산물은 5′ 인산·3′ OH입니다.
이후 CIP/rSAP 등으로 인산을 제거하면 OH로 달라질 수 있으므로 마지막 처리 이력을 확인하세요.
3′ OH 및 이중가닥 양쪽의 동일한 말단 상태도 확인해야 합니다.

돌출 말단·Taq의 3′ A 돌출·한쪽만 인산화·수정 올리고·3′ 차단기·IVT RNA의 삼인산/cap은 현재 서열 모델에 해당하지 않습니다.
일반적인 표준 NTP의 무cap·무말단처리 IVT RNA는 보통 5′ 삼인산이며 인산1개와 구별합니다.
준비 방법 예시는 선택 안내이고 앱이 시료의 화학 상태를 확인하거나 자동 선택하는 기능은 아닙니다.
모르면 주문서/성적서/처리 기록을 확인하거나 알려진 전체 MW·명시적 평균 근사를 사용하세요.

검증·복사·데이터 처리

독립 합성 기준의 단위·MW·가닥/말단/원형·부분 계산·오류/복사와 로컬 브라우저 검증을 대상으로 합니다.
기존 독립 합성 기준의 핵산 수치·Thermo·Vector/Copy 시험과 앱 표시/입력/복사 계약 검사를 게시 전 자동 회귀에 포함합니다.
사용자 실제 시료·성적서·Excel·실험 검증은 확인 전이며 배포 버전과 실사용 확인 상태를 구별하여 표시합니다.
정의된 소수 상수와 입력은 정확 유리수로 연산하고 결과는 최대12유효숫자로 표시합니다.
작은 값≤0.001/큰 값≥1E12는 지수표시합니다.
계산 자릿수가 측정·분자량 모델의 불확실성을 없애지 않습니다.

조건·방법·NA·중간 반올림·웹 기준 출처/확인일·계산 서열·버전을 포함한3열 text/HTML복사를 제공하며 HTML은 맑은고딕9pt·테두리 없음입니다.
자유 텍스트는 HTML escape와 스프레드시트 수식 문자 보호를 적용합니다.
입력은 브라우저 메모리에서 처리하고 자동 저장·외부 전송·로그·도구 간 자동 전달은 없습니다.
