처리 위치
브라우저 메모리. 입력 자동 저장·외부 전송 없음.

계산 방법

같은 용질에서 C1V1=C2V2를 적용하며 몰↔질량 조합은 직접 입력 MW로 농도 기준을 통일합니다. 원하는 양 만들기: Stock 사용량 = 목표 농도 × 최종 부피 ÷ Stock 농도. 전량 희석: 최종 부피 = Stock 농도 × 보유 Stock 부피 ÷ 목표 농도. 희석액 추가량 = 최종 부피 − Stock 사용량.

M~fM의 몰농도와 g~fg 및 L/mL/µL 조합의 질량농도를 지원합니다. 부피 단위는 L/mL/µL입니다. 질량↔몰은 사용자 직접 분자량(g/mol)으로 환산합니다. 길이/서열 기반 MW·핵산 copy 수·다중 성분 배합은 별도 도구의 역할입니다.

시약 조제

직접 입력한 MW(g/mol)와 목표 몰농도로 계산합니다. 필요한 질량[g] = 몰농도[mol/L] × 최종 부피[L] × MW[g/mol]. 보유 질량으로 맞출 최종 부피[L] = 질량[g] ÷ (몰농도[mol/L] × MW[g/mol]). 시약을 용해한 뒤 용매로 최종 부피까지 맞춥니다. 고체 시약이 포함된 최종 용액 부피이며 용매 첨가량 자체로 표시하지 않습니다. 순도·용해도·용매 종류는 자동 보정/판단하지 않습니다. 이 팝업도 기존 희석/환산과 독립 상태입니다.

몰↔질량 빠른환산

농도(M~fM ↔ g~fg/L·mL·µL) 또는 총량(mol~fmol ↔ g~fg)을 양방향 환산합니다. 질량농도[g/L] = 몰농도[mol/L] × MW[g/mol], 질량[g] = 물질량[mol] × MW[g/mol]. 입력 MW는 같은 물질 전체의 값이며 염형/수화물·조성을 자동 확인하지 않습니다. 직접 MW 출처는 미기록입니다.

팝업과 메인 입력은 독립 상태입니다. 농도/총량·방향·단위·값·MW를 바꾸면 이전 결과/복사를 무효화합니다. 0인 환산값은 허용하지만 MW는 양의 값이어야 합니다. 메인 희석의 농도/부피는 양의 값이어야 합니다.

결과와 복사

원본 입력을 유지하고 Stock량·희석액 이론량·최종 부피·희석 배수를 구별합니다. 입력 조건을 바꾸면 이전 결과와 복사를 무효화합니다. 결과는 최대12유효숫자로 표시하고0이 아닌0.001이하 또는1E12이상은 지수 표기합니다. 입력 소수/단위는 정확 유리수로 계산합니다.

조건·단위·사용한 분자량·방법·버전을 포함한3열 HTML/일반텍스트 복사를 제공합니다. HTML의 맑은고딕9pt 지정과 실제Excel 서식 유지는 구별합니다. 실제Excel/사용자 조제 확인은 아직 하지 않았습니다. 파일 export/자동저장/다른도구 자동전달은 없습니다.

한계와 검증

균일 혼합·부피 가산을 가정한 이론 부피입니다. 실제 최종부피 기준 조제에서는 해당 부피까지 맞춥니다. 희석액 종류·시약 안정성·피펫 가용 범위·실험 성능/임상 판단을 자동 결정하지 않습니다. Stock보다 높은 목표/목표0/비양의 부피/잘못된 수치는 차단합니다.

합성 기대값·단위/오류·모드와 화면/복사를 로컬에서 확인한 검증판입니다. 사용자 실사용·실제Excel·장비/실험 성능 검증과 구별합니다.

희석 입력은 다른 도구로 자동 전달하지 않습니다.
