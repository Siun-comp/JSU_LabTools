검사법 비교 분석

동일 검체의 Reference·Product 결과를 전체, 검출값 구간, 채취일별로 비교합니다.

열기 ↗실사용 확인 전

입력

검체 ID, 채취일, Reference 결과, Reference 검출값, Product 결과, Product 검출값의 6열을 XLSX·UTF-8 CSV/TSV 또는 붙여넣기로 입력합니다. 검출값은 Ct/Tt 모두 사용할 수 있으며 별도 종류 선택이나 수집기관 입력은 없습니다. 기존 양식의 헤더는 자동 인식하고 없으면 첫 행부터 읽습니다. 중복 ID는 행별로 유지합니다. 예제는 합성 자료입니다.

ID 누락 또는 입력한 날짜·수치·결과의 형식 오류는 전체 분석에서 제외하고 원행과 사유를 보존합니다. 날짜 공란은 날짜 분석만 제외합니다. 수치 공란은 가능한 정성 비교를 유지합니다. ND는 검사 후 미검출로 음성이며 0을 대입하지 않습니다. 수식은 실행하지 않습니다. 파일20 MB/압축 해제60 MB/입력10,000행 이하를 지원합니다.

비교와 구간

PPA·NPA·OPA와 Exact/Wilson CI, 양쪽 Positive이면서 두 숫자가 있는 검체의 Pearson·OLS·잔차·예측구간(PI)을 제공합니다. 전체 입력의 기준 모델은 필터로 다시 적합하지 않습니다. 그룹별 상관·회귀는 별도 요약입니다. Reference 구간의 Product 검출률, 채취일 구간의 PPA/NPA, 같은 수치쌍의 Reference/Product 중앙값을 막대그래프로 표시합니다. CI와 Q1–Q3는 표에서 확인합니다.

D1–D6 날짜 경계는 달력 또는 직접 입력으로 지정합니다. 하한 포함·상한 제외이고 마지막은 최종 경계 이상입니다. 모두 비우면 개별 날짜별로 분석합니다. 날짜 없는 검체도 가능한 나머지 분석에 포함합니다. 분모가 없으면 대상 없음이며 0%와 구별합니다.

결과 전달

현재 결과의 표·해석 주석을 복사하거나 그래프만 PNG로 복사할 수 있습니다. Excel 리포트는 9개 분석 시트와 7개 편집 가능한 그래프, 전체 원본·현재 범위 검체·제외 사유를 포함합니다. 본문은 맑은 고딕9pt이며 제목·강조 크기만 조절할 수 있습니다. 리포트는 저장 시점의 분석 결과이며 Excel에서 입력을 수정해도 자동 재계산하지 않습니다.
