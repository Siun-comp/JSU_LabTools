계산 기준·출처

ID 누락 또는 입력한 날짜·수치·결과의 형식 오류가 있으면 행을 전체 분석에서 제외하고 원행과 제외 사유는 보존합니다. 입력하지 않은 날짜는 날짜 분석만 제외합니다. 정성 비교는 유효 결과 쌍, 수치 관계·paired 중앙값은 양쪽 Positive이면서 두 유효 숫자가 있는 검체를 사용합니다. ND는 음성이며 수치 0이나 최대 cycle을 대입하지 않습니다. 중복 ID는 합치지 않습니다.

유효 결과 중 검출률은 Reference 양성 중 Product 유효 결과를 분모로 합니다. 평가 가능률은 분석 적격 Reference 양성 중 Product 유효 결과의 비율입니다. Invalid·미입력은 별도 표시하며, 미인식은 전체 입력 검증에서 집계합니다. 날짜가 없어도 날짜 분석 외의 가능한 분석은 유지합니다.

회귀는 Product = 절편 + 기울기 × Reference의 OLS입니다. 전체 입력의 적격 검체로 회귀선을 만들고 표시 범위를 바꿔도 잔차·PI의 기준 모델은 유지합니다. 그룹별 상관·회귀는 별도 요약입니다. PI 이탈은 추가 검토 대상이며 자동 제외·합격 판정하지 않습니다.

Median [Q1–Q3]는 분포 요약이며 CI가 아닙니다. 사분위수는 Excel QUARTILE.INC의 포함형 보간을 사용합니다. 각 시험법의 척도를 유지하며 Ct/Tt 직접 차이·자동 동등성 판정은 제공하지 않습니다.
