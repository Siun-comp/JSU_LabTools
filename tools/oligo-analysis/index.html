방법·표시·지원 범위

DNA 혼합염기는 실제 서열로 전수 확장합니다. 같은 primer의 Self에는 서로 다른 variant의 교차 결합도 포함합니다. 최저 점수는 가능한 후보이며 발생확률이 아닙니다. 입력한 서열은 자동 저장·외부 전송하지 않습니다.

IDT 기준은 각 역평행 정렬의 최저 에너지 연속 구간에 Breslauer propagation ΔG25를 적용합니다. 실선은 에너지 구간, 점선은 추가 상보 결합입니다. 염·loop·시작 보정을 합산하지 않습니다. 붉은 경고는 반올림 전 ΔG ≤ −9이며, 그보다 약한 3′ 말단 연속 3 bp는 별도 주의 표시입니다. 필터 공란은 검출 구조 전체이며 원계산은 유지합니다. 표시할 구조가 0개인 조합은 목록과 복사에서 제외합니다.

Thermo는 optimal sensitivity 3의 원본 검출·정렬 도식만 표시합니다. 추가 cut-off·ΔG·−9 경고·3′ 보충 검출을 적용하지 않습니다. 혼합염기 결과는 실제 서열 확장 후의 로컬 분석이며 vendor의 혼합문자 입력 결과와 동일하다고 주장하지 않습니다.

Polydimer는 세 실제 분자 사이의 두 연속 상보 결합 구간(각 2 bp 이상)을 비겹치게 배치한 후보입니다. 같은 primer의 반복 분자도 포함하고, 겹침을 피한 짧은 구간과 대체 정렬도 탐색합니다. 두 구간이 각각 −9 이하인 경우와 약한 구간이 포함된 경우를 구분합니다. 구간 점수 합에는 가닥 결합 비용·loop·접합부·대칭 보정이 없으며 실제 복합체 ΔG가 아닙니다. 고리형 세 접촉·hairpin 경쟁·4가닥 이상·3D 구조·평형 농도·실제 증폭은 평가하지 않습니다.

지원 예산은 primer당 실제 서열 1,024개, Self/Hetero 합계 탐색 가중치 5천만·예상 정렬 행 25만입니다. Polydimer는 가닥당 60 nt까지 지원합니다. 예상 조합 수·작업량은 경고로 안내하며 경고 확인 후 진행할 수 있습니다. 비겹침 구간을 정렬·검색하고, 실행 시간 30초 또는 계산 자료의 추정 보관량 128 MiB에 도달하면 미완료로 중단합니다. 추정 보관량은 계산 자료의 관리값이며 브라우저 전체 메모리 실측이 아닙니다. 이는 이 도구의 자원 관리 기준이며 생물학적 기준이나 모든 기기의 시간 보장이 아닙니다. 상한 도달·사용자 제외는 구조 없음과 구분합니다.

일반 DNA 기준값과 혼합염기·표시·범위 선택을 합성 사례로 확인했습니다. 모든 서열의 vendor 완전 일치·임상/실험 성능 검증은 아닙니다.
