계산 조건

수정·염형·말단을 포함한 해당 분자의 성적서 MW를 입력하세요.
앱이 값을 보정하지 않습니다.

기본 Vector 서열을 입력창에 넣습니다.
실제 시료의 구조는 아래에서 선택하세요.
insert 추가·기존 구간 제거는 자동으로 하지 않습니다.
pcDNA3.1(+) 공개 파일은 모호염기 S가 있어 불러오기에서 제외했습니다.

일반 서열 또는 이름이 있는 FASTA 한 기록.
이중가닥은 완전 상보 가닥을 함께 계산합니다.
공백·줄바꿈은 제외하며 원문은 유지합니다.
최대 400,000문자·200,000 nt/bp입니다.
한도를 넘는 원문은 자르지 않고 계산 오류로 표시합니다.

내 시료는 어떤 말단인가요? · 준비 방법으로 확인

선형은 끝이 열린 모양을 뜻합니다.
5′ 말단의 인산 유무는 서열만으로 알 수 없으며 주문한 수정과 마지막 효소 처리 이력으로 확인합니다.

제한효소로 자른 DNA는 일반적으로 5′ 인산·3′ OH입니다.
이후 CIP/rSAP 등으로 말단 인산을 제거했다면 OH 조건에 해당합니다.
다만 돌출 말단(sticky end)·Taq의 3′ A 돌출은 현재 완전 상보 서열 모델에서 지원하지 않습니다.
blunt end라도 최종 서열·말단을 확인하세요.

일반 화학 합성 RNA와 시험관 전사(IVT) RNA는 구별하세요.
표준 NTP로 전사하고 cap·말단 처리를 하지 않은 IVT RNA의 5′ 말단은 보통 삼인산입니다.
삼인산이나 cap은 ‘5′ 인산1개’ 조건에 해당하지 않으며 현재 서열 모델에서 지원하지 않습니다.

3′ 말단은 두 조건 모두 OH입니다.
이중가닥은 양쪽 가닥의 말단 조건이 같고 완전 상보인 경우만 계산합니다.
한쪽 프라이머만 인산화한 산물·형광/quencher 수정 올리고·3′ 차단기는 이 모델에 해당하지 않습니다.

모르면 임의로 선택하지 말고 주문서·성적서·프라이머 수정·마지막 효소 처리를 확인하세요.
해당 분자의 전체 MW를 알면 직접 MW를, 길이로 근사할 목적이면 평균법을 명시적으로 선택할 수 있습니다.

무수 유리산·평균 질량 기준의 이론 MW입니다.
Na 등 counterion·수화물·수정·모호염기·overhang·nicked Plasmid는 지원하지 않습니다.
해당 MW를 아는 경우 직접 MW를 사용하세요.

환산 결과

농도와 필요한 분자량 근거를 입력하세요.

핵산 농도 환산 결과
항목값단위

Copy는 전체 분자 수입니다.
이중가닥 한 분자=1copy.
소수는 평균 기대량이며 검출 성공·표적 수·임상 판정을 뜻하지 않습니다.

방법·적용 범위·검증 안내

질량농도[g/L] ÷ MW[g/mol] = 몰농도[mol/L].
몰농도 × 선택한 환산 기준의 NA = copies/L.
기존 근사·서열·직접 MW는 정확한 NA(6.02214076E23 mol⁻¹)를 유지합니다.
NEBioCalculator 및 Thermo Copy Calculator 기준은 웹툴의 NA(6.022E23 mol⁻¹)를 적용합니다.
Thermo 기본650·질량농도 입력은 웹툴처럼 copies/ng를 먼저 정수 반올림하고, Copy/NA로 몰농도를 표시합니다.
Thermo 몰/Copy 입력은 해당 MW·NA로 역환산하며 웹 화면 재현 범위 밖입니다.
세 농도 종류를 양방향으로 환산합니다.
MW가 없으면 가능한 결과만 표시합니다.
선택한 방법의 입력이 잘못되면 계산을 차단하며 평균법으로 자동 전환하지 않습니다.

서열법은 단일 일반 DNA/RNA의 이론 모델입니다.
선형에는 5′ OH 또는 5′ 인산·3′ OH, 원형에는 완전 폐환 조건을 적용합니다.
선형 이중가닥은 두 가닥에 동일한 말단 조건을 적용합니다.
서열은 자동 T/U 변환·modification 삭제를 하지 않으며 원문을 보존합니다.
일반 서열법은 정확한 전체 서열·구조·말단과 이 화학 기준이 맞을 때 평균법보다 구체적인 이론값입니다.
수정이나 염형이 반영된 성적서 MW가 있으면 직접 MW가 더 적합할 수 있습니다.
Thermo Fisher Chemistry Guide의 DNA 올리고 계산은 sodium salt(pH 7) 기준이므로 현재 무수 유리산 모델과 다릅니다.
정밀 모델과 농도 측정의 정확성은 별개입니다.

값은 최대12유효숫자로 표시하며 0이 아닌0.001 이하 또는1E12 이상은 지수표시합니다.
Copy 결과는 선택한 단위에서 1000 이상이면 같은 값을 소수 두 자리·3유효숫자 지수 요약으로도 표시·복사합니다.
형식은0.00E+00, 예: 1.00E+03=1000, 1.00E+06=1000000.
주값은 선택한 계산 기준을 따릅니다.
웹툴의 표시 자릿수와 다를 수 있으며 지수 요약은 반올림 전 주값을 대체하지 않습니다.
정의된 소수 상수와 입력의 내부 연산은 정확 유리수입니다.
성분 질량 상수/근사/측정의 불확실성이 없어지는 것은 아닙니다.
HTML 복사는 맑은고딕9pt·테두리 없는3열이며 일반텍스트에는 글꼴이 없습니다.
사용자 실제 시료·성적서/Excel 확인은 아직 수행하지 않았습니다.
