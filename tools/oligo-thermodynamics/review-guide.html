검토 항목과 합성 테스트 예시

통합 베타 v0.2.0-beta.1 · 2026-10-30. 공개 화면에서 아래 서열을 직접 입력해 확인할 수 있습니다. 예시는 소프트웨어 동작 확인용이며 실험 성공·속도·형광 기준이 아닙니다.

먼저 확인할 공통 조건

반응온도60°C, Na50mM, K/NH₄0, Mg total3mM, dNTP total0.8mM, 실제 A/B 각200nM. 별도 THAL API와 NN 동량 참고농도 C_ref는 각각200nM입니다. 참고농도와 실제 농도를 같은 것으로 해석하지 마세요.

초기화는 입력·보관을 모두 지우므로 필요한 결과를 먼저 내보내세요. 새로고침/종료 시 자동 복원하지 않습니다. 원격 사용자도 이 공개 페이지와 분석 화면만으로 검토할 수 있습니다.

우선 검토할 화면·동작

  1. PC/휴대폰·브라우저200%에서 버튼 글자가 잘리거나 입력/오류 문구가 옆 칸을 덮지 않는지 확인합니다. 긴 서열·표/구조 영역의 자체 스크롤과 페이지 전체 가로 밀림을 구분합니다.
  2. 시작/끝 핸들·숫자·±1·방향키·길이 고정이 같은 좌표를 가리키는지 확인합니다. 원본을 줄이면 좌표를 다시 확정하도록 안내해야 합니다.
  3. 범위/온도 변경 직후 이전 결과가 만료되고, 자동 계산 후 최신 좌표/조건이 표시되는지 확인합니다. 온도 격자/전체 관계는 수동 실행입니다.
  4. 미지원·미입력·구조 미검출이 숫자0으로 표시되지 않는지, 입력 확인 버튼이 해당 칸으로 이동하는지 확인합니다.
  5. 보관3슬롯과 기준/현재 결과가 구분되는지, 다른 반응/모델의 차이를 임의로 만들지 않는지 확인합니다.
  6. plain/HTML 복사·TXT/CSV에서 방향·부모 좌표·단위·조건을 확인합니다. 전체 원본 A/B 포함은 각각 명시적 옵션입니다. 붙여넣는 앱에서 고정폭 글꼴을 유지하지 않으면 좌표 목록을 함께 보세요.

예시1 — 기본·경계·말단·온도

전체 후보 서열에 아래13nt를 입력합니다.

GCGCTTTAAGCGC

  1. 기본에서 시작1/끝13을 선택합니다. 실제 Mg 보정 Tm과 별도 Mg0 참고 에너지가 구분되어야 합니다. Hairpin은 원래 조건의 Primer3 결과입니다.
  2. 시작2/끝12로 바꾸고 길이11nt·서열·좌표가 함께 바뀌는지 확인합니다. 길이 고정 후 구간을1nt 이동해 길이가 유지되는지도 봅니다.
  3. 말단에서 n=5를 선택합니다. A5′는 B3′, A3′는 B5′에 대응하는 독립 조각입니다. 전체에서 말단 값을 뺀 수치를 실제 말단 풀림 에너지로 해석하지 않습니다.
  4. 온도에서55~65°C·간격5°C를 설정하고 직접 실행합니다.55/60/65의3점과 각 조건을 확인합니다. 격자 계산이 끝난 뒤 조건을 바꾸면 기존 격자는 만료되어야 합니다.

예시2 — 두 가닥과 실제 B 초안

A는 아래20nt, 수동 B는 그 역상보입니다. 두 입력은 모두5′→3′입니다.

A: ATGCGCGATCTAGCTAGCGA
B: TCGCTAGCTAGATCGCGCAT

두 가닥 탭에서 A/B hairpin·AA/BB/AB를 확인합니다. B 일부를 고친 뒤 다른 탭으로 갔다 와도 수동 초안이 유지되어야 합니다. ANY 정렬은 자동으로 다른 대응을 선택할 수 있으며 지정 mismatch 위치의 고정 손실값이 아닙니다. 구조 미검출은 실험에서 결합하지 않는다는 뜻이 아닙니다.

예시3 — Conventional Beacon

전체 후보에서 인식 영역 R20nt를 선택하고 Beacon 탭에서 S5를 입력합니다. S3는 역상보 연동, Target은 아래 값을 별도 입력하고 전체20nt를 선택합니다.

R: ATGCGCGATCTAGCTAGCGA
S5: CGCGC
S3(연동): GCGCG
Target: TCGCTAGCTAGATCGCGCAT

조립 Beacon 길이는30nt입니다. 전체 Beacon/Target hairpin·stem 제외 R–Target·전체 Beacon–Target의4반응과 원본 좌표를 확인합니다. 의도 site는 Target 전체1~20으로 지정할 수 있습니다. 반환 hairpin이 지정 stem과 정확/일부/대체 중 무엇인지 읽으세요. 지정 stem과 정확 일치한다고 가정한 예시가 아닙니다. S5를 바꿔도 독립 R–Target 입력은 같지만 실제 Beacon 접힘/경쟁은 달라질 수 있습니다. 네 에너지를 빼서 closed→bound 순에너지로 만들지 않습니다.

예시4 — 고정 단일 G·T mismatch

관계·mismatch 탭의 A/B에 아래25nt를 각각 넣고 전체 범위를 선택한 뒤 고정 정렬로 전환합니다.

A: AAGAACGTACGTACGTACGTACGTA
실제 B: TACGTACGTACGTACGTACGTTTTT
PM 비교용 B: TACGTACGTACGTACGTACGTTCTT

  1. A local3/B local23의 G·T와 부모 좌표를 확인합니다. 아래 B는3′→5′로 표시됩니다. 가상 PM에는 실제 B 부모 좌표가 없어야 합니다.
  2. 기본 조건의 Na-only/Mg0 참고에서 PM ΔG 약−9.52, MM 약−6.75kcal/mol, MM−PM ΔΔG 약+2.77kcal/mol·ΔTm 약−5.03°C를 확인합니다. 화면 반올림 수치입니다. 새 실측 목표값이 아닙니다.
  3. 실제 B를 위 PM 비교용 B로 바꾸면0 mismatch·차이0이어야 합니다. 미지원에0을 채우는 것과 구분합니다.
  4. C_ref를200→600으로 바꾸면 Tm은 바뀌고 같은 온도의 G/H/S는 유지되어야 합니다. C_ref를 비우면 G/H/S는 남고 Tm만 미확정이어야 합니다.
  5. 요청 Mg를 바꿔도 fixed의 적용 Mg0/Na-only 안내는 유지되어야 합니다. 함께 표시한 실제 Mg THAL과 fixed 수치를 서로 차감하지 않습니다.

예시5 — 관계 여러 개·부분 계산·출력

관계1에 예시2를, 관계2에 예시4를 각각 넣습니다. 용도를 qPCR/LAMP/OSD 등으로 바꿔도 입력 서열/조건이 자동 변경되지 않아야 합니다. 관계 묶음의 전체 계산은 두 관계×3=6항목입니다. 선택 관계만 자동 갱신한 것을 전체 최신 snapshot으로 표시하지 않아야 합니다.

B를 비우면 가능한 A hairpin만 남아야 합니다. 관계를 제외했다가 복원하면 초안이 보존되어야 합니다. 선택 행 보관·전체 snapshot CSV·다른 탭과 혼합 보관을 확인하세요. 서로 다른 반응을 공통 점수나 전체 순ΔG로 합치지 않습니다.

예시6 — 오류와 미지원의 정상 처리

  • 서열에 N 또는 문자를 넣으면 ACGT 입력 오류를 읽을 수 있어야 합니다. 긴 오류 문구가 버튼/입력을 덮지 않아야 합니다.
  • 고정 모드 A=AAGAACTAA, B=TTAGCTCTT는 A.C pH 근거 미확인으로 fixed 수치 미지원입니다. 선택 THAL 참고가 가능해도 그 값을 fixed 자리에 넣지 않습니다.
  • A/B 길이를 다르게 하거나 mismatch를2개 만들면 fixed 미지원이어야 합니다. 자동 절삭/재정렬하지 않습니다.
  • Na=0이면 Na-only fixed 참고 수치는 미지원입니다. 이를 실제 반응의 모든 계산 불가능과 혼동하지 않습니다.
  • 시작을 끝보다 크게 입력하거나 원본을 짧게 바꾼 뒤 안내와 좌표 재확정 경로를 확인합니다.

문제 보고 시 탭·공개 버전·합성 입력/범위·조건·조작 순서·브라우저/화면 폭·기대/실제 결과를 함께 기록하면 재현에 도움이 됩니다. 실제 연구 서열을 공유할 필요는 없습니다.
