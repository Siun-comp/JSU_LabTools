채택 모델과 구현 기준

A/B hairpin은 primer3-py2.3.1의 고정 Primer3 THAL C/파라미터를 사용합니다. THL_GENERAL·maxLoop30·입력 온도/이온 조건을 전달하며 원본과 WASM의 수치·구조·상태 재현을 필수 기준으로 삼습니다. Primer3Plus는 Primer3의 웹 인터페이스이며 모든 웹 기본 설정이 이 도구와 같다는 뜻은 아닙니다.

Mg=0 duplex는 별도 DNA_NN4/SantaLucia entropy salt 모델로 고정 완전 상보 DNA/DNA·1 M 표준상태·ΔCp=0 근사입니다. Mg가 있으면 별도 DNA_NN4/Owczarzy2008 Tm 전용 분기로 계산합니다. 비자기상보 유효 농도는 max(A,B)−min(A,B)/2, 자기상보는 같은 종의 총농도 A+B와 symmetry를 사용합니다.

반응 온도는 ΔG°(T)에 반영합니다. 같은 조건의 고정 duplex에서 ΔH/ΔS/Tm은 분석 온도만 바꿔도 일정하며, hairpin은 해당 온도에서 매번 다시 계산합니다. 미검출과 유효한0/양수/음수 값을 구분합니다.

실측 평가와 구현 일치

추가 Mg Tm은 Biopython1.88 DNA_NN4/saltcorr7과 독립 JS 구현을 대조합니다. 같은 공식의 구현 일치이며 새 실측 예측 정확도 검증이 아닙니다. 짧은 구간·극단적인 이온 조건으로 실측 성능 보장을 확대하지 않습니다.

초기 duplex228조건을 명시한 표·염·농도 convention의 독립 구현과 대조했습니다. 후속 공개12서열·144조건에서 구조OFF/ON 각각 native288회/WASM288회를 비교해 기존 수치 허용오차를 만족했습니다. 같은 C의 이식 일치이며 독립 실험 서열 수는 아닙니다.

문헌 duplex Tm348조건/108고유 서열의 초기 MAE는1.48°C였습니다. 1996년 원문 two-state23서열의 ΔG37/H/S MAE는 각각0.243kcal/mol·6.522kcal/mol·21.148cal/(mol·K)였습니다. NN 개발 계보·고염/짧은 서열 자료로, 독립 최종 성능 보장이 아닙니다.

2025년 용액상 UV hairpin12건은 원문의 약75mM 총 Na를 반영해도 Tm MAE14.73°C·최대40.10°C, ΔG37 MAE2.07kcal/mol의 차이가 남았습니다. 모두16nt·목표6bp stem/4nt loop 자료이며 다른 길이/loop/조건을 대표하지 않습니다. 이 오차를 개별 후보의 신뢰구간이나 보정 상수로 사용하지 않습니다.

이 한계를 보존하면서 고정 Primer3 모델의 재현 가능한 예측값을 제공합니다. 실측 오차 해소·실험 정확도 인증·IDT 동일값·반응 성공을 보장하지 않습니다.

지원 범위

Mg>0 입력에서는 ‘Mg=0 참고’ duplex ΔG/ΔH/ΔS/Tm을 별도로 계산·표시합니다. Mg만0으로 바꾸고 나머지 입력은 보존하며, dNTP 독립 효과는 기존 모델에서 반영하지 않습니다. 이 참고값은 입력 Mg 조건의 에너지 예측이나 ΔΔG로 사용하지 않습니다. 단가염 합계0이면 참고값의 로그 정의역이 없어 제공하지 않으며 임의의 염 농도를 넣지 않습니다. 화면·보관·TXT/CSV에 입력 조건과 참고 조건을 구분해 남깁니다.

사용자 지정 시작 조건은 반응 온도60°C·Na50mM·K/NH₄0mM·Mg total3mM·dNTP total0.8mM·A/B각200nM입니다. 첫 로드와 초기화에 적용하며 직접 편집할 수 있습니다. 일반적인 반응 권장 조성이나 정확도 검증 조건을 뜻하지 않습니다.

계산 입력은 선택2~60nt·일반 A/C/G/T·반응 온도0~100°C입니다. 제품/자원 범위이며 전체 범위의 실측 정확도 검증이 아닙니다. 부모는 정규화10,000nt/raw100,000자 이내입니다.

Mg 포함 duplex는 Tm·Tm−반응 온도를 제공하며 ΔG/ΔH/ΔS·ΔΔG는 미지원입니다. 단가염·서열 GC/길이·Mg-dNTP 결합 근사를 반영한 역수 Kelvin 보정이며 K=3×10⁴ M⁻¹를 사용합니다. 실제 적용값에 freeMgM(모델 근사)·monoM·ratio·branch·correctionInverseK를 기록합니다. 동일 이온·모델·반응 정의의 보관값 사이에서는 ΔTm만 비교할 수 있습니다. Hairpin은 Primer3의 Mg total/dNTP total 염 근사를 사용하며 실측 free Mg를 계산한 것이 아닙니다. K/NH4는 단가염 합산 근사입니다. Tm 전용 보정을 H/S/G에 임의 적용하지 않습니다.

선택 밖 부모 folding·RNA/hybrid·mismatch·LNA/MGB·표지/첨가제·효소/시간축·속도·형광/Cq/Tt·자동 최적 순위는 지원하지 않습니다. 원본 좌표는 출처이며 선택 영역을 독립 oligo로 취급합니다.

결과와 개인정보

자동 계산은 서열·구간·수치 조건 변경 후 160 ms 동안 추가 입력을 기다린 뒤 최신 불변 요청을 로컬 Worker에서 실행합니다. 유효한 숫자 좌표는 Enter 없이 반영합니다. 자동 계산을 끄면 ‘지금 계산’으로 실행할 수 있습니다. 이름·역할·메모 변경과 접기는 수치 재계산을 하지 않습니다.

매번 엔진 manifest·WASM·모델 모듈 해시를 확인합니다. 서열/범위/조건 변경은 현재 결과를 즉시 만료시키고 대기/실행 요청을 취소합니다. 취소/실패/늦은 응답에서 예전 수치를 되살리지 않습니다. 사용자 취소·오류 뒤에는 자동 반복 재시도를 하지 않으며 새 수치 입력 변경 또는 지금 계산으로 다시 실행합니다.

최대3개 보관값은 이 페이지 메모리에만 남으며 기준을 직접 선택합니다. 다른 온도/이온/반응 정의에서는 ΔΔG를 제공하지 않습니다. 농도 차이는 Tm 비교에 표시합니다. CSV 문자열의 수식 접두를 보호하고 원시 수치는 보존합니다.

입력 외부 전송·자동 저장이 없고 엔진은 동일 출처 정적GET으로 취득합니다. 새로고침/페이지 종료/상단 초기화 시 보관도 지워집니다. 전체 원문은 명시적인 내보내기 옵션 선택 시에만 해당 snapshot 원문을 포함합니다.
