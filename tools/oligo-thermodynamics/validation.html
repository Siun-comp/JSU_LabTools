반응 온도는 ΔG°(T)에 반영합니다. 같은 조건의 고정 duplex에서 ΔH/ΔS/Tm은 분석 온도만 바꿔도 일정하며, hairpin은 해당 온도에서 매번 다시 계산합니다. 미검출과 유효한0/양수/음수 값을 구분합니다.

Mg>0 입력에서는 ‘Mg=0 참고’ duplex ΔG/ΔH/ΔS/Tm을 별도로 계산·표시합니다. Mg만0으로 바꾸고 나머지 입력은 보존하며, dNTP 독립 효과는 기존 모델에서 반영하지 않습니다. 이 참고값은 입력 Mg 조건의 에너지 예측이나 ΔΔG로 사용하지 않습니다. 단가염 합계0이면 참고값의 로그 정의역이 없어 제공하지 않으며 임의의 염 농도를 넣지 않습니다. 화면·보관·TXT/CSV에 입력 조건과 참고 조건을 구분해 남깁니다.
