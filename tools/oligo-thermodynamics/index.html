두 가닥 THAL 분석의 범위

선택 A·상대 B의 각 hairpin과 AA/BB/AB 결합을 같은 작업 공간에서 봅니다. B 직접 입력은 A 이동에도 초안을 유지합니다. THAL의 Mg 입력 G/H/S는 원본 염 근사의 모델값이며 아래 NN4 Mg0 참고값과 구분합니다. 같은 길이·구조에서는 Mg 변화에 따른 순위가 보존될 수 있지만 길이/접촉수·구조가 다르면 순위 역전도 가능합니다. 실제 Mg 에너지 오차·미세 후보 우열·속도·형광은 검증되지 않았습니다.

말단·온도 비교의 범위

말단의5′/3′는 선택 A 기준이며 A5′는 B3′, A3′는 B5′와 결합합니다. 각 fragment에 입력 농도를 적용한 별도 짧은 duplex 모델입니다. 전체 분자의 말단 풀림 에너지·Primer3 disruption 점수·효소 신장 속도와 같지 않습니다. 겹친 구간을 합해 전체 값을 만들지 않습니다.

말단 차이는 같은 n·온도·이온·모델·자기상보 반응 정의에서만 계산합니다. Mg0 참고값의 자동 ΔΔG는 제공하지 않습니다. 반응 온도와 Tm을 구별하고, 계산 Tm이0~100°C 밖이라고 자르지 않습니다.

온도 비교는 표이며 결합률·형광·용융곡선이 아닙니다. 고정NN의 H/S/Tm은 온도만 바꿔도 같고 ΔG가 변합니다. 선택한 전체 A/B hairpin은 각 온도에서 실제 다시 계산하므로 선택 구조·H/S/Tm이 달라질 수 있습니다. Mg0 duplex와 입력Mg hairpin을 직접 빼서 경쟁 구조의 승자를 판정하지 않습니다.

같은 모델·온도·조건에서 비교하세요. ΔH·ΔS는 ΔG를 구성하는 함께 해석할 값이며 보편적인 합격 범위는 없습니다.

ΔG° · 표준 Gibbs 자유 에너지 변화

Mg 입력이 있으면 별도의 ‘참고 · Mg=0’ 블록에서 Mg만 제외한 ΔG°·ΔH°·ΔS°·Tm을 제공합니다. 반응 온도·Na/K/NH₄·A/B 농도는 같고 dNTP 독립 효과는 반영하지 않습니다. 이 값에 입력 Mg의 안정화 효과가 포함되었다고 해석하지 마세요. 입력 Mg 조건의 보정 Tm은 별도로 표시합니다.

선택한 반응 온도에서 구조 형성이 열역학적으로 얼마나 유리한지 나타내는 모델값입니다. 단위는 kcal/mol입니다. 같은 온도·염·모델·반응 정의에서 ΔG°가 더 음수이면 형성이 더 유리합니다. 0에 가깝거나 양수인 값은 그 표준 상태에서 형성의 이득이 작거나 불리함을 뜻합니다.

관계식은 ΔG°(T) = ΔH° − T × ΔS°입니다. T는 Kelvin(°C + 273.15)이며, 이 화면의 ΔS°는 cal/(mol·K)이므로 1,000으로 나눠 kcal 단위를 맞춥니다. Mg=0 duplex는 고정 결합 구조·ΔCp = 0 근사입니다. 기존 NN4의 Mg 조건은 Tm 전용 보정이므로 ΔG°·ΔH°·ΔS°를 제공하거나 Tm에서 역산하지 않습니다. Hairpin은 각 반응 온도에서 Primer3를 다시 실행하므로 선택 구조와 ΔH°·ΔS°도 달라질 수 있습니다.

°는 표준 상태를 뜻합니다. 실제 농도에서의 ΔG = ΔG° + RT ln Q와 구분하세요. ΔG°만으로 결합된 분율·실제 평형 농도·시간을 알 수 없습니다. 같은 정의의 이상적 평형에서는 ΔG° = −RT ln K° 관계가 있지만 이 도구는 경쟁 구조를 포함한 평형 분율이나 결합 속도 상수를 계산하지 않습니다.

예를 들어 같은 조건의 duplex ΔG°가 −12와 −9라면 첫 후보의 형성이 모델상 더 유리합니다. 에너지가 더 음수라고 annealing 속도가 비례해 빨라지거나 형광이 높아지는 것은 아닙니다. Duplex 형성과 A/B 각각의 분자 내 hairpin은 반응 정의가 다르므로 숫자를 직접 빼서 경쟁 반응의 승자를 판정하지 않습니다.

ΔH° · 엔탈피 변화

‘참고 · Mg=0’ 블록의 ΔH°는 입력 Mg 효과를 제외한 기존 NN4 모델값입니다. 입력 Mg 조건의 ΔH°로 대체하지 않습니다.

결합 또는 접힘 전후의 엔탈피 차이로, 일정 압력에서의 열 교환과 관련됩니다. 단위는 kcal/mol입니다. 음수는 모델상 구조 형성 시 열을 방출하는 방향을 뜻합니다. 염기 stacking·수소 결합·용매와 이온 등의 순효과를 반영하는 파라미터이므로 수소 결합 개수만 센 값은 아닙니다.

결합 형성이라는 같은 반응 정의에서 다른 조건이 같다면 더 음의 ΔH°는 엔탈피 기여에 유리합니다. 덜 음의 ΔS°는 엔트로피 비용이 작은 방향입니다. 실제 서열에서는 두 값이 함께 변할 수 있으므로 각각을 독립적인 성능 점수로 쓰지 않습니다.

ΔH°가 더 음수라는 이유만으로 최종 결합이 더 강하다고 결론내리지 마세요. ΔS°와 온도를 함께 넣은 ΔG°가 판단의 기준입니다. 길이가 길면 ΔH°의 크기도 커질 수 있어 서로 다른 길이의 값을 염기당 우수성 점수로 사용하지 않습니다.

Mg=0 duplex에서는 ΔCp = 0 근사로 온도를 바꿔도 같은 서열·조건의 ΔH°를 유지합니다. 이는 온도 전 구간에서 실제 엔탈피가 일정하다는 실험적 보장이 아닙니다. Hairpin은 온도별 선택 구조에 따라 달라질 수 있습니다.

ΔS° · 엔트로피 변화

기존 NN4의 입력 Mg 조건 ΔS°는 미지원이며, Mg=0으로 따로 계산한 참고 ΔS°를 구분해 제공합니다. Tm 보정은 엔트로피 보정과 동일하지 않습니다.

구조 형성 전후의 전체 엔트로피 차이입니다. 단위는 cal/(mol·K)이며 ΔG°·ΔH°와 1,000배 단위 차이가 있습니다. 가닥의 자유도 감소뿐 아니라 용매·이온 효과를 포함하는 모델값입니다. DNA 구조 형성에서는 흔히 음수이지만 DNA만의 ‘무질서도’와 동일시하지 않습니다.

ΔS°가 음수이면 −TΔS° 항은 양수가 되어 구조 형성에 비용으로 작용하며, 온도가 올라갈수록 그 비용이 커집니다. 더 음수인 ΔS°만을 좋은 결합 지표로 사용하지 마세요. ΔH°와 상쇄되어 최종 ΔG°가 결정됩니다.

단위 계산용 가상 예시: ΔH° = −80 kcal/mol, ΔS° = −220 cal/(mol·K)이면 37°C에서 ΔG° = −11.767 kcal/mol, 65°C에서 −5.607 kcal/mol입니다. 실제 후보의 계산 결과나 정확도 검증 사례가 아니며, H/S가 고정된 경우의 온도 효과만 보여 줍니다.

Tm · melting temperature

Tm · Mg는 입력 Mg/dNTP를 반영한 값이고, 참고 블록의 Tm · Mg=0은 Mg를 제외한 별도 값입니다. 참고 G/H/S와 Mg 보정 Tm을 섞어 하나의 열역학 값 세트로 해석하지 않습니다.

Mg가 있으면 DNA_NN4의 1M 기준 Tm에 Owczarzy2008의 역수 Kelvin 보정을 적용합니다. 단가염·GC·길이와 Mg-dNTP 결합 근사(결합 상수3×10⁴ M⁻¹)를 반영합니다. 실제 적용값에는 계산한 free Mg·보정 분기·계수를 남깁니다. Mg=0의 entropy 보정 모델과 구분하며, 매우 짧은 선택 구간은 탐색적 예측으로 해석하세요. 새 Mg 실측 정확도 검증을 통과한 값이라는 뜻은 아닙니다.

염·농도·반응 정의와 모델에 따른 용융 전이 온도(°C)입니다. Duplex는 입력한 A/B 농도와 자기상보 여부를 반영한 모델의 전이 정의를 사용합니다. 두 농도가 다른 경우의 유효 농도 정의는 ‘이번 계산의 적용값·모델·한계’와 계산 근거 페이지에서 확인할 수 있습니다. 모든 상황에서 전체 가닥의 절반이 결합하는 단일 온도로 해석하지 마세요.

Hairpin은 한 분자 안의 접힘 전이이며 두 가닥 결합과 정의가 다릅니다. Hairpin Tm을 duplex Tm과 동일한 농도 의존성으로 해석하지 않습니다. Hairpin의 ΔG°는 입력한 반응 온도에서 평가하므로 Tm과 같은 온도에서 계산한 값이라는 뜻도 아닙니다.

Tm이 높을수록 해당 모델의 구조가 더 높은 온도까지 유지되는 경향을 비교할 수 있지만, 반응 성공·적정 annealing 온도·실제 결합 속도를 직접 정하지는 않습니다. Duplex Tm은 농도 항을 포함하므로 ΔG° = 0이 되는 온도와 일반적으로 같지 않습니다.

Tm−반응 온도 · 온도 여유

모델 Tm에서 입력한 실제 반응 온도를 뺀 참고값(°C)입니다. 양수는 반응 온도가 Tm보다 낮고, 음수는 더 높다는 뜻입니다. 이 차이 자체에 보편적인 합격선은 없으며 결합률·분자 접근성·속도를 보장하지 않습니다. 구조 미검출·미지원일 때는 숫자를 만들지 않습니다.

온도가 다른 두 결과의 ΔG° 차이를 같은 조건의 결합 우열로 판단하지 마세요. 보관·비교의 ΔΔG는 같은 온도·이온·모델·반응 정의에 한해 후보−기준으로 제공합니다. 음수이면 후보의 해당 duplex 형성이 더 유리한 방향입니다. 가닥 농도가 다르면 Tm 비교에 그 차이가 표시됩니다.

Hairpin 구조 표기·복사

seq는 선택 가닥의 5′→3′ 서열, str은 같은 좌표의 dot-bracket 표기입니다. 서로 대응하는 괄호는 염기쌍, 점은 비결합 염기입니다. ‘염기쌍 좌표’는 독립 oligo의 1-based 위치입니다. THAL 원문은 별도로 보존하며 변환 검증에 실패하면 파생 구조를 만들지 않습니다.

구조 복사는 조건·엔진·서열·구조·좌표를 함께 제공합니다. 일반 텍스트에는 글꼴이 전달되지 않으므로 붙여넣는 앱에서 Consolas 등의 고정폭 글꼴로 보세요. 서식 포함 복사를 지원하는 편집기에서는 고정폭 표현을 함께 전달하지만 모든 앱의 동일한 표시를 보장하지 않습니다. Word 등에서 대상 서식으로 붙여넣으면 글꼴이 바뀔 수 있으므로 원본 서식 유지 또는 HTML 형식 붙여넣기를 선택하세요. 좌표 목록은 글꼴과 무관하게 염기쌍을 확인하는 용도입니다.

Hairpin과 독립 영역 근사

Hairpin은 독립 A/B 각각의 모델상 구조입니다. 반환 구조가 있어도 설정 온도에서 불리할 수 있으며 미검출은 모든 구조가 없거나 빠르게 결합한다는 보장이 아닙니다. 부모의 선택 밖 서열과 연결된 전체 분자의 접근성/ensemble은 계산하지 않습니다.

Primer·Probe에 적용할 때

LAMP FIP/BIP에서는 F2/B2의 표적 결합과 F1c/B1c가 관여하는 구조 형성을 구분하세요. 부분 영역의 값을 연결된 전체 primer·생성 산물의 안정성이나 LAMP 효율로 대체하지 않습니다.

OSD는 toehold와 초기 duplex를 순서대로 선택·보관해 비교할 수 있습니다. 각 값은 해당 영역의 완전 상보 상대에 대한 독립 결합 근사이며 합산해 전체 치환 반응 에너지로 만들지 않습니다. Assimilating probe도 표적 인식과 reporter–quencher 결합을 나눠 확인할 수 있지만 효소에 의한 편입·strand displacement 속도는 별도입니다.

Hydrolysis qPCR에서 primer–표적과 probe–표적은 보통 서로 다른 부위의 결합입니다. Probe 결합이 충분하지 않으면 신호가 증폭을 충분히 반영하지 않을 가능성이 있지만 낮은 Tm만으로 primer가 먼저 붙어 probe를 막는다고 단정할 수 없습니다. 온도가 다른 반응 단계는 각각의 온도로 계산·보관하세요. 형광·Cq/Tt·효소 신장/절단은 예측하지 않습니다.

표준 비변형 DNA 모델이므로 LNA/MGB·염료/quencher·첨가제·효소 효과를 임의 보정하지 않습니다. 고정 정렬 단일 내부 mismatch는 별도 NN3/IMM·Na-only 참고 모드입니다. 전체 반응 시뮬레이션·자동 최적 순위·에너지 그래프·기존 도구 데이터 연계는 없습니다. 입력은 브라우저 메모리에서 처리하며 자동 저장·외부 전송하지 않습니다.
