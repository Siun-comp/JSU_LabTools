분석 범위

사용자가 정리한 한 분석 집단의 데이터를 받습니다. LOT별 계산이 필요하면 집단을 나누어 분석합니다. 여러 LOT를 자동 합치거나 전체시험 결과로 확정하지 않습니다.

원자료·시험일·재검 이력·시험설계 관리는 Excel에서 유지합니다. 허가 적합성을 자동 판정하지 않습니다.

공식 Excel 양식은 선택한 모듈에만 적용하며, 작업 JSON은 확인 후 네 모듈 입력을 모두 복원합니다. v1/v2 자동 이관은 지원하지 않습니다. 작업 파일은 암호화되지 않으므로 연구 데이터 보관 규칙에 따라 관리하세요.
