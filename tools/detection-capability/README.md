# LoB · LoD · LoQ 분석 — JSU LabTools 파생판

개발·배포: Jang Si Un. 파생 프로그램 v0.9.1-beta.1 / 계산 기준 프로그램 v0.9.0-beta.6. JSU LabTools에서 사용하는 포털 파생 베타입니다. 사용 검토용 베타이며 인증 프로그램 또는 허가 적합성 자동 판정 도구가 아닙니다.

분자진단 개발·성능평가 자료를 LoD, 개발 LoD confirmation, LoB, LoQ의 제한된 기존 방법으로 분석합니다. 원자료·시험설계·시장별 허가 적합성은 별도로 검토해야 합니다. 상세 방법·계산 환경·프로그램 버전은 결과의 계산 근거와 작업 JSON을 확인하세요.

## 계산·이력

LoD·검출률 확인·LoQ는 webR의 R을 사용하며 LoB는 JavaScript 비모수 순위식입니다.
원 프로그램의 공개/전환 이력은 화면에서 원 프로그램 이력으로 구별합니다.
새 결과에는 새 프로그램 버전을 기록하고 저장된 과거 결과의 버전을 소급 변경하지 않습니다.
회사 보고서나 원자료를 개발자에게 공유할 필요는 없습니다.

## 사용

1. HTTP/HTTPS로 제공되는 index.html을 엽니다. 최종 사용자에게 Node/R 설치나 계산 서버는 필요하지 않습니다. 파일 더블클릭 모드는 R 분석을 지원하지 않습니다.
2. 공식 빈 양식 또는 원하는 합성 예제를 다운로드합니다. 필요한 시트만 작성합니다. 합성 예제/사전 기준은 시험용이며 허가자료 또는 권장 시험설계가 아닙니다.
3. 파일 확인 → 대상 시트 입력 적용 검토 → 확인 후 교체 → 분석 실행 순으로 진행합니다. 직접 입력·Excel 붙여넣기도 지원합니다.
4. 표·그래프만 복사, 상세 계산 기록 복사, 3시트 Excel 결과서를 사용합니다. 결과서의 셀 수정으로 통계가 재계산되지 않습니다.
5. 새로고침/업데이트 전 작업 JSON을 저장합니다. 복원된 입력은 다시 계산해야 합니다. 실제 입력이 개발자의 합성 예제로 자동 교체되지 않습니다.

## 다운로드/네트워크

입력 데이터는 브라우저에서 처리하며 분석/Excel 작성 API로 업로드하지 않습니다. 앱 서버는 정적 파일을 제공합니다. 첫 R 분석은 고정 webR0.6.0/R4.6.0 계산 환경을 외부 CDN에서 다운로드하고 LoD에서 MASS7.3-65를 준비합니다. 네트워크/CDN 제한으로 준비가 실패하면 연결 확인 후 재시도하세요. 검증 버전이 다르면 계산을 차단합니다.

환경이 준비된 같은 세션에서 offline 계산/Excel 생성이 가능합니다. 새로고침 후 재다운로드 필요 여부는 브라우저 캐시에 따라 달라지며 영구 offline 설치를 보장하지 않습니다. 외부 정적 환경 요청에는 분석 입력을 넣지 않지만 서비스 제공자에게 일반 연결 정보(IP 등)가 전달될 수 있습니다.

지원 검증은 Chrome의 제한된 개발검사입니다. 실제 Excel 화면/인쇄·OS clipboard·다른 브라우저·최종 사용자 검토는 별도입니다. 데이터가 바뀌면 다시 계산하세요.

## 출처/배포

이 도구는 공통 assets와 포털 복귀 경로를 사용합니다. 이 폴더만 따로 게시하지 말고 JSU LabTools의 전체 게시 산출물을 사용합니다. 프로젝트 전체를 공개 저장소에 올리지 마세요. GitHub Pages에서 사용하는 베타이며 회사 시험의 적용 기준·최종 보고와 허가 적합성을 자동 확정하지 않습니다. 앱 자체의 별도 오픈소스 라이선스는 이 패키징 과정에서 임의로 부여하지 않았습니다.
