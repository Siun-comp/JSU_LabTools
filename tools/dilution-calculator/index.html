시약·버퍼 조제

버퍼를 선택하고 최종 부피와 농도를 지정하여 성분별 사용량을 계산합니다.

읽는 중

버퍼 조제표

입력은 자동 저장·외부 전송하지 않습니다.

조성 설명·출처

성분을 녹이거나 혼합한 뒤 최종 부피를 맞추세요. 높은 배수는 용해도·안정성을 확인한 뒤 사용하세요. 출처 pH는 해당 배수·조건의 참고값이며 입력 변경에 따라 자동 보정되지 않습니다.

아래는 1X 기준 농도입니다. 10X 원액을 만들려면 제조 농도에 10을 입력하세요.

버퍼 성분과 조제 사용량
시약조제 방법목표 농도 (1X)MW 또는 보유 Stock사용량삭제
용매최종 부피 맞춤——계산 후 표시—

용매 자체의 성분·pH 조절량은 계산에 포함되지 않습니다.

고체는 실제 염형·수화물의 MW(g/mol)를 입력하세요. 질량농도는 MW가 필요 없습니다. Stock은 해당 시약의 보유 농도이며, 10X·100X 버퍼 원액도 X 단위로 입력할 수 있습니다.

농도와 MW 또는 Stock 농도를 입력하고 계산하세요.

실사용 확인 전

몰↔질량 환산

농도와 총량을 구별하여 환산합니다. 메인 조제표와 입력·결과가 독립적입니다.

라벨·성적서의 해당 물질 분자량을 직접 입력하세요. 길이/서열로 추정하지 않습니다.

고체 역계산

보유 질량·MW·목표 몰농도로 만들 수 있는 최종 부피를 계산합니다. 메인 조제표와 독립적으로 동작합니다.

라벨·성적서의 해당 화학형 분자량(g/mol)을 입력하세요.

용해 후 최종 부피까지 맞추는 기준입니다. 용매 첨가량 자체가 아닙니다.

단일 희석

같은 시약의 Stock 희석을 계산합니다. 메인 조제표와 입력·결과가 독립적입니다.

계산 모드

입력 조건

같은 시약의 분자량을 라벨·성적서에서 확인하여 입력하세요. 몰↔질량 환산에만 사용합니다.

Stock과 희석액을 합친 최종 전체 부피입니다.

같은 시약으로 입력하세요. 몰↔질량을 선택하면 분자량을 직접 입력합니다. 소수와 1E-3 같은 지수 표기를 사용할 수 있습니다.

조제량

조건을 입력하고 ‘희석 계산’을 누르세요.

희석 조제 결과
항목부피단위

희석액 추가량은 부피 가산을 가정한 이론값입니다. 실제 최종 부피 기준 조제에서는 해당 최종 부피까지 맞추세요.

계산 방법 · 사용 안내

같은 용질에서 C₁V₁=C₂V₂를 적용합니다. 원하는 양 만들기: Stock 사용량 = 목표 농도 × 최종 부피 ÷ Stock 농도. Stock 전량 희석: 최종 부피 = Stock 농도 × 보유 Stock 부피 ÷ 목표 농도.

몰↔질량 조합은 직접 입력한 MW로 환산합니다. 희석액 추가량은 부피 가산의 이론값이며, 실제로는 목표 최종 부피까지 맞춥니다. 목표 농도가 Stock보다 높으면 희석으로 만들 수 없습니다.
