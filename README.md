# JSU LabTools

Desktop tools for molecular diagnostics development. Personal use first.

Portal v0.2.0 includes the independent existing IsoAmplar Plot Analysis T link and Oligo Mix tool v0.3.1 / algorithm v0.3.0. Sequence, concentration conversion and Amplification Analysis remain pending.

Oligo Mix performs browser-local theoretical volumes and manual preparation-volume review. Plasmid supports mass, molar and copies units with explicit conversion basis. No experiment inputs are sent to a server, stored automatically or passed between tools.

Actual Excel paste/font/merge behavior and user workflow verification are pending. Clipboard HTML specifies Malgun Gothic 9pt; paste values uses destination formatting. Computational tests and browser clipboard checks do not establish instrument or experimental performance.

Build the complete static artifact with `node scripts/build.mjs`, then verify with `node scripts/verify.mjs`. The complete manifest preserves prior published paths. Internal development documents, attachments, original workbooks and validation files are excluded from this public checkout.
